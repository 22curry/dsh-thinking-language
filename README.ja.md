# dsh-thinking-language

[English](README.md) | [中文](README.zh.md) | **日本語** | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português](README.pt.md)

**DeepSeek Harness** のモデルが「考える」言語を DSH の設定から選べます — 中国語、英語、ドイツ語、フランス語、スペイン語、ポルトガル語、日本語、韓国語など。

この選択は会話ではなくプロファイルに属します。新しいセッション、別のワークスペース、サブエージェント、再起動 — どれも設定を引き継ぎます。一度設定すれば済みます。

---

## なぜ必要か

モデルの思考（chain of thought）はモデル自身が生成するもので、使う言語もモデルが決めます。その決定に働きかけられる唯一の場所は、思考を始めるリクエストです。このプラグインはシステムプロンプトに短いセクションを 1 つ加え、推論に使う言語を指定します。結果として思考は**最初のトークンから**その言語で書かれます。

- 追加のモデル呼び出しなし、翻訳サービスなし、遅延なし
- データはマシンの外に出ません
- ユーザーに見える返答は、ユーザーが書いた言語のままです

## インストール

**DSH の UI から**

1. このフォルダを任意の場所に置きます。
2. サイドバーの **Plugins** → **Add plugin** → **Install a third-party plugin**。
3. このフォルダの絶対パス（例 `C:\Users\you\dsh-thinking-language`）を貼り付けてインストールします。
4. **Installed plugins** に表示され、インストール後は有効になります。

**npm から**（公開後）

```bash
dsh plugin add dsh-thinking-language
```

## 使い方

**設定** → **思考言語** を開き、言語を選ぶだけです。

同じコントロールは **Plugins** のバンドルページにも表示されます。どちらから変更しても同じ値が読み書きされます。

| 選択肢 | 効果 |
| --- | --- |
| 会話に合わせる（デフォルト） | プロンプトに何も追加されず、モデルは従来どおりに動きます。 |
| `中文`、`English`、`日本語`、`한국어`、`Deutsch`、`Français`、`Español`、`Português`、`Italiano`、`Русский`、`العربية`、`हिन्दी`、`ไทย`、`Tiếng Việt`、`Türkçe`、`Bahasa Indonesia` | モデルはその言語で推論します。 |
| その他の言語… | 一覧にない言語を自由入力できます（例 `Norwegian`、`Cantonese`）。 |

変更は次のモデルリクエストから有効になります。再起動は不要です。

## 仕組み

- ホスト側はシステムプロンプトのセクションを 1 つ（`thinking-language`、order `10300`、組み立て後の最後）登録します。中身は 2 行の指示です。*会話に合わせる* のときはテキストが空になり、セクションごと消えるのでデフォルトのコストはゼロです。
- 選択値はこのプラグイン自身の設定エントリです（profile patch の `thinking-language`）。volatile フィールドなので、書き込みがその場で反映され、次のリクエストが新しい値を読みます。
- ブラウザ側は共有の設定フォームサービスで 2 つの入り口を描画し、どちらも Host の設定ドキュメント経由で書き込みます。だから再起動しても残り、すべてのセッションで共有されます。

## プライバシーとコスト

ネットワークアクセス、テレメトリ、認証情報のいずれもありません。指示は**言語を選んでいるときだけ** 1 リクエストあたり約 50 トークンです。デフォルトでは一切送信されません。

## 制限

- 思考を公開するモデルにのみ効きます。思考を出さないモデルには影響しません。
- 指示はモデルが従うもので、ハーネスが強制するものではありません。ごく短いタスクでは会話の言語に戻ることがあります。
- 言語を変えるとシステムプロンプトの接頭辞が変わるため、その時点からプロバイダのキャッシュが 1 回作り直されます。
- 古いセッションに記録済みの思考は書き換えも翻訳もされません。

## 開発

```bash
node --check index.js
node --check client.js
```

上記の方法でフォルダをインストールしてください。HMR が有効なプロファイルならホスト側はその場で再読み込みされ、ブラウザ側は登録した client モジュールと一緒に再読み込みされます。
