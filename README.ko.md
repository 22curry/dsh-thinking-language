# dsh-thinking-language

[English](README.md) | [中文](README.zh.md) | [日本語](README.ja.md) | **한국어** | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português](README.pt.md) | [Русский](README.ru.md) | [العربية](README.ar.md)

**DeepSeek Harness** 모델이 생각하는 언어를 DSH 설정에서 고를 수 있습니다 — 중국어, 영어, 독일어, 프랑스어, 스페인어, 포르투갈어, 일본어, 한국어 등.

이 선택은 대화가 아니라 프로필에 속합니다. 새 세션, 다른 워크스페이스, 서브에이전트, 재시작 모두 설정을 그대로 이어받습니다. 한 번만 정하면 됩니다.

---

## 왜 필요한가

모델의 사고 과정은 모델이 스스로 생성하며, 어떤 언어를 쓸지도 모델이 정합니다. 그 결정에 개입할 수 있는 유일한 지점은 사고를 시작시키는 요청입니다. 이 플러그인은 시스템 프롬프트에 짧은 섹션 하나를 더해 추론 언어를 지정합니다. 그래서 사고는 **첫 토큰부터** 그 언어로 작성됩니다.

- 추가 모델 호출 없음, 번역 서비스 없음, 지연 없음
- 데이터가 기기 밖으로 나가지 않습니다
- 사용자가 보는 답변은 사용자가 쓴 언어를 그대로 따릅니다

## 설치

**DSH UI에서**

1. 이 폴더를 원하는 위치에 둡니다.
2. 사이드바의 **Plugins** → **Add plugin** → **Install a third-party plugin**.
3. 이 폴더의 절대 경로(예: `C:\Users\you\dsh-thinking-language`)를 붙여넣고 설치합니다.
4. **Installed plugins** 에 나타나며, 설치 후 바로 켜집니다.

**GitHub에서**

```bash
dsh plugin add github:22curry/dsh-thinking-language --profile <name>
```

DSH 데스크톱에서는 **Plugins → Add plugin** 에 `github:22curry/dsh-thinking-language` 를 붙여넣으세요. 데스크톱 앱은 자체적으로 프로필을 관리하므로 CLI를 쓰지 않습니다.

**npm에서** (배포 후)

```bash
dsh plugin add dsh-thinking-language
```

## 사용

**설정** → **思考 언어** 를 열고 언어를 고르면 끝입니다.

같은 컨트롤이 **Plugins** 의 번들 페이지에도 나옵니다. 어디서 바꾸든 같은 값을 읽고 씁니다.

| 선택 | 효과 |
| --- | --- |
| 대화 따라가기(기본값) | 프롬프트에 아무것도 추가되지 않고 모델은 이전과 똑같이 동작합니다. |
| `中文`, `English`, `日本語`, `한국어`, `Deutsch`, `Français`, `Español`, `Português`, `Italiano`, `Русский`, `العربية`, `हिन्दी`, `ไทย`, `Tiếng Việt`, `Türkçe`, `Bahasa Indonesia` | 모델이 그 언어로 추론합니다. |
| 다른 언어… | 목록에 없는 언어를 직접 입력합니다(예: `Norwegian`, `Cantonese`). |

변경은 다음 모델 요청부터 적용됩니다. 재시작은 필요 없습니다.

## 동작 방식

- 호스트 쪽은 시스템 프롬프트 섹션 하나(`thinking-language`, order `10300`, 조립된 프롬프트의 마지막)를 등록하고, 그 안에는 두 줄짜리 지시가 들어갑니다. *대화 따라가기* 일 때는 텍스트가 비어 섹션이 사라지므로 기본값의 비용은 0입니다.
- 선택값은 이 플러그인 자체의 설정 항목입니다(profile patch 의 `thinking-language`). volatile 필드라서 설정 쓰기가 즉시 반영되고 다음 요청이 새 값을 읽습니다.
- 브라우저 쪽은 공용 설정 폼 서비스로 두 진입점을 그리고, 둘 다 Host 설정 문서를 통해 씁니다. 그래서 재시작해도 남고 모든 세션에서 공유됩니다.

## 개인정보와 비용

네트워크 접근, 텔레메트리, 자격 증명이 전혀 없습니다. 지시는 **언어를 선택했을 때만** 요청당 약 50 토큰입니다. 기본값에서는 전혀 전송되지 않습니다.

## 제한

- 사고 과정을 노출하는 모델에만 영향을 줍니다. 사고를 보여주지 않는 모델은 그대로입니다.
- 지시는 모델이 따르는 것이지 하네스가 강제하는 것이 아닙니다. 아주 짧은 작업에서는 대화 언어로 돌아갈 수 있습니다.
- 언어를 바꾸면 시스템 프롬프트 접두사가 바뀌므로 그 시점부터 프로바이더 캐시가 한 번 다시 만들어집니다.
- 예전 세션에 이미 기록된 사고는 다시 쓰이거나 번역되지 않습니다.

## 개발

```bash
node --check index.js
node --check client.js
```

위 방법으로 폴더를 설치하세요. HMR 이 켜진 프로필에서는 호스트 쪽이 그 자리에서 다시 로드되고, 브라우저 쪽은 등록한 client 모듈과 함께 다시 로드됩니다.
