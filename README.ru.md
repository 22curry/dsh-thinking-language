# dsh-thinking-language

Выберите в настройках DSH язык, на котором думают модели **DeepSeek Harness** — китайский, английский, немецкий, французский, испанский, португальский, японский, корейский и другие.

Выбор относится к профилю, а не к диалогу: новые сессии, другие рабочие пространства, субагенты и перезапуски его сохраняют. Достаточно настроить один раз.

---

## Зачем это нужно

Цепочку рассуждений модели генерирует сама модель, и язык она тоже выбирает сама. Повлиять на это можно только в одном месте — в запросе, который запускает рассуждение. Плагин добавляет в системный промпт короткий раздел с указанием языка. В результате рассуждение **пишется на этом языке с первого токена**:

- без дополнительных вызовов модели, без сервиса перевода, без задержек;
- ничего не покидает вашу машину;
- видимый ответ по-прежнему следует языку пользователя.

## Установка

**Из интерфейса DSH**

1. Положите эту папку в любое место.
2. В боковой панели: **Plugins** → **Add plugin** → **Install a third-party plugin**.
3. Вставьте абсолютный путь к папке (например `C:\Users\you\dsh-thinking-language`) и установите.
4. Пакет появится в **Installed plugins** и будет включён после установки.

**С GitHub**

```bash
dsh plugin add github:22curry/dsh-thinking-language --profile <name>
```

В DSH Desktop вместо этого вставьте `github:22curry/dsh-thinking-language` в **Plugins → Add plugin**: настольное приложение управляет профилем само, CLI его не обслуживает.

**Из npm** (после публикации)

```bash
dsh plugin add dsh-thinking-language
```

## Использование

Откройте **Настройки** → **思考语言**, выберите язык — готово.

Тот же элемент управления есть на странице пакета в **Plugins**; оба читают и пишут одно и то же значение.

| Вариант | Действие |
| --- | --- |
| Следовать диалогу (по умолчанию) | В промпт ничего не добавляется, модель ведёт себя как раньше. |
| `中文`, `English`, `日本語`, `한국어`, `Deutsch`, `Français`, `Español`, `Português`, `Italiano`, `Русский`, `العربية`, `हिन्दी`, `ไทย`, `Tiếng Việt`, `Türkçe`, `Bahasa Indonesia` | Модель рассуждает на этом языке. |
| Другой язык… | Свободный ввод для того, чего нет в списке (например `Norwegian`, `Cantonese`). |

Изменения применяются со следующего запроса к модели; перезапуск не нужен.

## Как это работает

- Host-часть регистрирует раздел системного промпта (`thinking-language`, порядок `10300`, последний в собранном промпте) с инструкцией из двух строк. При выборе *Следовать диалогу* текст пустой, и раздел исчезает — значение по умолчанию ничего не стоит.
- Выбор хранится в конфигурации самого плагина (`thinking-language` в патче профиля). Поле volatile: запись применяется на месте, и следующий запрос читает новое значение.
- Браузерная часть рисует две точки входа через общий сервис форм конфигурации; обе пишут через документ настроек Host. Поэтому значение переживает перезапуски и общее для всех сессий.

## Приватность и стоимость

Ни доступа к сети, ни телеметрии, ни учётных данных. Инструкция стоит около 50 токенов на запрос **только когда язык выбран**; при значении по умолчанию она не отправляется.

## Ограничения

- Действует только на модели, которые показывают свои рассуждения.
- Инструкцию выполняет модель, а не harness — на очень коротких задачах она может вернуться к языку диалога.
- Смена языка меняет префикс системного промпта, поэтому кэш провайдера один раз перестраивается с этого места.
- Уже записанные рассуждения в старых сессиях не переписываются и не переводятся.

## Разработка

```bash
node --check index.js
node --check client.js
```

Установите папку как выше; с HMR Host-часть перезагружается на месте, а браузерная — вместе с клиентским модулем, который она регистрирует.
